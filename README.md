# memoraéBUILD Tracker

Inventory, sales and profit monitoring for **memoraéBUILD LEGO Minifigure Keepsakes** — bookings, pop-up markets, stock, supplies, payroll, transportation, event profit and business health KPIs.

## Use it

- **Online:** open the GitHub Pages site for this repo.
- **Offline:** download the repo and double-click `memoraeBUILD-tracker/index.html`.

No install or account needed. It's plain HTML, CSS and JavaScript.

## Where your data lives

Records are saved in the browser you use (localStorage), **not** in this repository. Each browser/computer, and each address (online site vs. local file), keeps its own separate data.

Use **Data & Backup → Download backup** regularly, and **Restore from backup** to move your records to another browser or computer.
